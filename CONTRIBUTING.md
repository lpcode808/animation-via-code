# Adding a lesson

A lesson belongs here if it changed what you'd do on the next video.

- Say it as an instruction ("Limit peaks before encoding"), then one line on why.
- Tag it **tentative** until it has held up across several pieces; then **confirmed**.
- If it contradicts an existing lesson, don't delete either; add it to "Where the notes disagree" in guide/appendix.md.
- No names of students, private people or private workspaces.
