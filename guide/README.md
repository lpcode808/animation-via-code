# Guide

The lessons are filed by the stage where you'll need them, in the order you'll meet them. Each stage has its lessons first, then the specific bugs (pitfalls) that cost time there.

| Stage | What it covers |
|---|---|
| [1. Plan the piece](1-plan.md) | Decide what the video teaches, in what order and how long each idea holds, before any code exists. |
| [2. Pick a renderer](2-renderer.md) | Choose what draws the frames for this subject, then get it working once. |
| [3. Build the scene on one clock](3-scene.md) | Write one timeline, and draw every frame from it. |
| [4. Sound and mix](4-sound.md) | Write the music and effects as code too, place them from the picture's own events, and measure the mix in the file you deliver. |
| [5. Render at scale](5-render.md) | Turn the scene into thousands of frames and one MP4 without babysitting it. |
| [6. Check it's right, then review](6-review.md) | Check the content first, then the frames, then ask someone who wasn't there. |
| [7. Make it legible](7-craft.md) | Sizes, contrast and small honesty labels that decide whether the video works on a phone or at the back of a room. |
| [8. Companion pages (optional)](8-companion-pages.md) | The same drawing code can power an interactive page next to the video. |
| [Appendix](appendix.md) | Working with the agent, cost and time, and where the notes disagree. |

Lessons are tagged **confirmed** (held up across many pieces), **tentative** (seen once or twice) or **contested** (sources disagree; see [where the notes disagree](appendix.md#where-the-notes-disagree)).
