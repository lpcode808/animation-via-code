# Demo prompts

Five prompts used to show the method live, each chosen to show something different. Rewritten generically.

## 1. A loop (shows: pure-function-of-time, seamless motion)

```
Make a 20 second looping video of the water cycle for 5th graders:
evaporation, condensation, precipitation, collection. The last frame
should match the first so it loops. Flat shapes, soft colours.
Captions, no narration.
```

## 2. A proof (shows: exact geometry, things code does better than a video model)

```
Make a 30 second video showing why a² + b² = c² using the classic
rearrangement of four triangles inside a square. Label the sides,
keep the triangles the same size throughout, and end on the equation.
Captions, no narration.
```

## 3. A myth-buster (shows: analogy → diagram → example order)

```
Make a 30 second video for high schoolers explaining why we have seasons.
Start by naming the common wrong idea (distance from the sun), then show
the tilt and how sunlight spreads over more ground in winter. End with a
question they can answer. Captions, no narration.
```

## 4. Bring your own handout (shows: grounding in your material)

```
Here is my handout [attach PDF]. Make a 30 second video that explains
the one idea students most often miss on it. Use only facts from the
handout. Captions, no narration.
```

## 5. The review pass (shows: the biggest quality lever)

Run [04-review-pass.md](04-review-pass.md) on whichever of the above finished first, then ask the agent to fix the top three problems and re-render.

## Running order that worked

Start #1 and #2 in parallel before talking, explain the method while they render, show #2 (it's the most convincing), then do #5 live on it.
